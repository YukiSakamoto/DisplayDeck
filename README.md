# DisplayDock

This is a simple example to show the Ardea model.

This program is available at <https://yukisakamoto.github.io/DisplayDeck>.

# How to Run

This program uses Vite (no global install needed).

```sh
npm install
npm run dev
```

# Build & Deploy (GitHub Pages)

```sh
npm run build
npx gh-pages -d dist
```

If this is the first deploy, enable GitHub Pages in the repo settings and set the source to the `gh-pages` branch.
